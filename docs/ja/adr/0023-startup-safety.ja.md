# ADR-0023: 起動時の安全機構 — 広すぎるルートと初回プロジェクト信用

| Field | Value |
|-------|-------|
| Status | **Accepted** |
| Date | 2026-08-20 |
| Binds | gem-agent |
| Decision makers | nlink-jp maintainers |
| Triggered by | オペレータ:「/ や ~ で起動した場合の確認・アラート」「初回起動のプロジェクトに AGENTS.md/GEMINI.md/CLAUDE.md/AGENT.md がある場合、信用して起動してよいか」 |

## Context

起動時の穴が 2 つ。第一に、作業ディレクトリはそのまま封じ込めの根になる:
`~` や `/` で起動すると「プロジェクトに封じ込め」は静かに「オペレータの
ホーム全域（あるいは全部）を file ツールが読み書きし、sandbox がシェルの
書き込みを許す」に化ける。第二に、checkout したてのリポジトリのエージェント
向けファイルは初回起動で無条件に尊重される: 指示ファイルは**指示として**
（信頼階層で）注入され、`.mcp.json` は**子プロセスを起動**し、
`.claude/skills` は `load_skill` 経由でオペレータ階層のコンテンツとして
ロードされる。ADR-0008 は未信頼プロジェクトからの承認緩和を既に拒否して
いるが、「clone して調べる」は依然として `cd` 一発で指示注入とプロセス実行の
距離にあった。

## Decision

1. **広すぎるルートは対話確認を要求する。** 広すぎる = ファイルシステムの
   ルート、ホームディレクトリ、ホームの祖先。プロンプトは帰結（file ツールと
   シェル書き込みがツリー全域に及ぶ）を名指しし、既定は No。非対話（`-p`・
   パイプ）ではエラーで拒否し、対話での確認経路を案内する。回答は意図的に
   **永続化しない** — そこで起動するのは稀で、1 キーは安い。
2. **初回信用の質問 1 つが、プロジェクトの提供物すべてを覆う。** 指示ファイル
   だけをゲートすると、`.mcp.json` が見た瞬間に実行される横で偽の安心になる。
   ゲートはプロジェクト自身の指示ファイル・`.mcp.json`・`.claude/skills` に
   及び、プロンプトには各項目が何を意味するか（サーバーエントリは子プロセスを
   起動する）を列挙する。祖先の指示ファイルとグローバル設定はゲートの外:
   clone はオペレータが所有する上位ディレクトリにファイルを置けない。
3. **回答はプロジェクトごとに 1 回、機械所有の policy.toml に永続化**
   （`[projects."<dir>"] trust = "granted" | "declined"` — 機械が書く
   プロジェクト別状態の置き場所は ADR-0009 の既決）。拒否してもセッションは
   起動する: そのプロジェクトの指示・MCP・skills をロードしないだけで、
   バナーがその旨と再確認のための編集先ファイルを示す。内容ハッシュでの
   再確認（known_hosts 方式）は提示の上で不採用: オペレータは自分の約 40
   リポジトリの指示ファイルを常時編集しており、編集のたびのプロンプトは
   釣り合う脅威のない摩擦である。
4. **手書きの信用宣言は上位:** `[approval].trusted_projects`（ADR-0008 の
   緩和許可リスト）に載ったプロジェクトは質問なしで信用される。ゲート対象の
   ファイルを何も提供しないプロジェクトは、何も聞かず何も記録しない。
5. **未決プロジェクトでの非対話実行は素で起動する** — 注入なし・プロジェクト
   MCP なし・プロジェクト skills なし・stderr に注記・決定は記録しない。
   拒否にすると checkout したてのリポジトリへの読み取り専用 `-p`
   パイプライン（正当な調査ワークフロー）が止まる。素の実行はその安全版で
   ある。

## Consequences

- `cd /tmp/clone && gem-agent` は、clone のファイルがプロンプトに届いたり
  何かを起動したりする前に 1 つ質問する。同じ clone への `gem-agent -p` は
  clone 由来の何もロードせずに走る。
- 既存の各プロジェクトでも初回起動で 1 回聞かれる（許容済みの摩擦）。
- プロンプトは TUI 開始前に stdin から**バッファなしで** 1 行読む —
  破棄されるバッファに先行入力が取り残されない。

## Alternatives considered

- **指示ファイルのみ**（当初案）— `.mcp.json` と skills まで拡大（§2）:
  狭いゲートは弱い経路を守ってプロセス実行を開けたままにする。
- **内容ハッシュ再確認** — 提示の上で不採用（§3）。
- **非対話の未信用実行を拒否** — 却下（§5）。
- **広すぎるルートの回答永続化** — 却下（§1）。
