# ADR-0002: 対話 UI — Bubble Tea inline TUI

| Field | Value |
|-------|-------|
| Status | **Accepted** |
| Date | 2026-08-18 |
| Binds | gem-agent |
| Decision makers | nlink-jp maintainers |
| Triggered by | Phase 2 完了後のオペレータ評価: 素の行 REPL は日常使用には厳しく、使って苦になるバックアップツールは訓練で使われなくなる |

## Context

Phase 1–2 は素の行ベース REPL を出荷した。機能的には完備だが:

1. **待機が無言** — 生成中・ツール実行中・MCP 呼び出し中のインジケーターが
   ない。「意図的に何もしない状態は UI で名乗らせる（無言の待機はハングに
   見える）」は組織の記録済み教訓である。
2. ユーザー入力・モデル出力・ツールイベント・承認プロンプトの視覚的区別がない。
3. 入力履歴・行内編集がない。RFP には履歴ナビが記載されていたが、raw mode
   エディタ自作は IME/CJK 破壊のリスクがあるとして Phase 1 では cooked mode を
   選び見送った。
4. Markdown が生テキストのまま。

本ツールの存在理由は「Claude Code の使えるフォールバック」であり、
使って不快なフォールバックは月次訓練で使われなくなり腐る。

## Decision

**Bubble Tea**（charmbracelet）を **inline レンダリング**で採用し、
bubbles（textarea・spinner）、lipgloss（装飾）、glamour（Markdown）を併用する:

- **inline 方式、alt-screen は使わない。** 完了した会話は `tea.Println` で
  ターミナル素のスクロールバックに流し、管理描画するのはライブ領域
  （ストリーミング中テキスト・ステータス行・入力ボックス）だけ。スクロール
  バック・検索・コピペが壊れない — Claude Code と同じ表示モデル。
- **入力**: 枠付き textarea。Enter で送信、ペーストされた改行は挿入扱い
  （bracketed paste はフラグ付きで届くため、複数行ペーストが行ごとの LLM
  コールになる事故は構造的に起きない）。手動改行は Ctrl+J。ArrowUp/Down の
  履歴ナビは**明示的なナビ中 state フラグの下でのみ**動作（ガードなしの
  Down ハンドラは下書きを破壊する、という記録済み教訓）。
- **承認ゲート**: agent goroutine の `Approve()` が `Program.Send` で TUI に
  要求を送り、応答チャネルでブロックする。TUI は y/n/a を受ける承認モードに
  切り替わる。セッション allowlist はゲート側に残す（TUI は判断を持たない）。
- **Markdown**: ストリーミング中はライブ領域に素のテキスト、ターン完了時に
  全文を glamour で整形してスクロールバックへ流す 2 段階方式。
- **非 TTY フォールバック**: stdin/stdout がターミナルでない場合は既存の
  素 REPL で動作（パイプのスモークテスト・スクリプト用途）。`-p` 単発モードは
  不変。「stdout はモデルテキストのみ」契約は非 TTY 経路に適用され、TUI
  モードではターミナル全体が単一の対話サーフェスになる。

## Consequences

- Phase 1 で cooked mode を選ばせた IME/CJK 懸念は解消: Bubble Tea の
  textarea は wide char 対応（go-runewidth）で、IME の変換合成はターミナル
  エミュレータ側で完了してから rune が届く。端末固有の preedit 問題が出た
  場合も素 REPL が逃げ道として残る。
- 依存が charmbracelet 系列に増える。許容: Go TUI の実質標準であり、代替の
  raw mode エディタ自作は既知の IME/CJK 罠である。
- agent コア（agent/llm/tools/mcp/sandbox）は無変更。変更は cmd + 新規
  internal/tui に閉じる。表示層が 2 つ（TUI + 素 REPL）になるが、素 REPL は
  非 TTY 経路として意図的に残すものであり deprecated ではない。

## Alternatives considered

- **行 REPL の ANSI ポリッシュ**（色 + スピナーのみ）— 最安だが履歴ナビと
  Markdown が残り、それらを入れる時に表示層を二度書きする。「段階実装して
  後から廃止」は組織の記録済みアンチパターン。
- **raw mode 行エディタの自作** — 依存ゼロだが、Phase 1 で見送った理由その
  ものである既知の IME/CJK 罠。却下。
- **alt-screen TUI（全画面）** — 実装は inline より楽だが、素のスクロール
  バックとコピペを壊す。会話ツールには不適。却下。
- **Wails/Tauri GUI** — RFP でスコープ外。gem-agent はターミナルツール。
