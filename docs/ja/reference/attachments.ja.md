# 添付: @ 参照

`@<パス>` でファイルやディレクトリをメッセージに添付できます。参照は
**あなたの打った入力**からしか解析されません — モデル出力やツール結果
からは決して解析されず、これが後述のプロジェクト外例外を安全にして
います。Tab で補完でき、添付できなかった参照は黙って捨てずに理由付き
で報告され、添付内容はツール出力と同様に**非信頼データとして隔離**
されてモデルに渡ります。

## ファイルとディレクトリ

`@src/main.go これ直して` と書くとファイル本体が指示と一緒に送られ、
`@docs/` ならディレクトリ一覧が送られます。参照はシンボリックリンク
経由も含めプロジェクト内に限定されます。

## 画像（ADR-0012）

スクリーンショットは第一級の入力です。入り口は 3 つ + モデル用に 1 つ:

| 経路 | 例 |
|---|---|
| プロジェクト内ファイル | `@docs/mock.png これを再現して` |
| どこからでも（画像のみ） | `@~/Desktop/スクリーンショット.png` |
| クリップボード | Cmd+Ctrl+Shift+4 のあと `@clipboard ここがおかしい` |
| モデル起点 | `view_image` ツール（プロジェクト封じ込め） |

MIME はバイト列から判別し（拡張子を偽ったバイナリは拒否）、画像は
1 枚 8MB・1 メッセージ 4 枚まで。超過は丸ごと拒否します — 切り詰めた
PNG は小さい絵ではなく壊れたファイルです。

画像は nonce ラップできないため、隔離の立場は枠書きで示します —
画像内に見えるテキストはデータであり指示ではない。これはタグ隔離より
弱く、ドキュメントはそう明言します。トランスクリプトはバイト列を保存
するので、resume したセッションは見ていたスクリーンショットごと復元
されます。

## 文書（ADR-0026）

PDF はそのままモデルへ — レイアウト・表・スキャンをネイティブに読み
ます（実測: オペレーター添付とツール応答内の両方で受理、後続ラウンド
もクリーン）。Word/Excel/PowerPoint（.docx/.xlsx/.pptx）は標準
ライブラリだけでローカルにテキスト抽出: 段落、タブ区切りのシート行、
番号付きスライド。

経路は ADR-0012 の分割どおり 2 つ — ファイルを選ぶのがあなたなら
`@report.pdf` / `@data.xlsx`（絶対・~ パス可 — 打ったのはあなた
自身）、モデルなら `read_document` ツール（プロジェクト封じ込め）。
レガシー .doc/.xls/.ppt は対象外と明言します。PDF は 12MB まで
（切り詰めた PDF は壊れたファイル）、Office は圧縮 32MB まで + 抽出
テキストに予算上限。

## 音声・動画（ADR-0027）

`@memo.m4a` / `@clip.mp4` で録音やクリップを添付（プロジェクト内・
絶対・~ パス）— モデルがネイティブに文字起こし・理解します。

`[gcp] bucket` 設定時、メディアは**常に** GCS バケット経由の `gs://`
URI になります（content-addressed・重複排除・アップロード中に
ハッシュ照合・gem-agent は削除しない — バケットのライフサイクル
ルールを設定してください）: インラインのバイト列は毎ラウンドの履歴
再送で送り直されるのに対し、URI は数十バイトです。バケット未設定なら
インライン 15MB まで、超過は両方の対処を名指して拒否。アップロードは
ターンの context 下で走るので Ctrl+C が届きます。

実測済み: インラインのボイスメモを正確に文字起こし、バケット経由の
動画は音声トラックと映像の両方から正答。

保持に関する帰結が 1 つ: `gs://` オブジェクトを参照する transcript は
毎ターンそれを再送します。ライフサイクルルールがオブジェクトを削除
した後は、ターンのエラーがその旨と回復手順（`/clear`、または添付を
過ぎるまで `/compact`）を名指しします。
