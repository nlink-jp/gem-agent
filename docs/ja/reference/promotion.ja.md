# 昇格基準: lab-series → cli-series

gem-agent は lab-series にある。この series の契約は「実験的。インターフェースは
予告なく変わりうる」である。フォールバックツールが欲しい契約はその逆 — 必要な日に
驚きなく動くことである。RFP（§6）はそれでも lab-series に置き、この緊張を明示した
うえで、月次[訓練](drill.ja.md)と、誰かが議論したくなる前に書いておく基準で緩和する
と決めた。本文書がその基準である。

基準は「急いでいる人がチェックできる」ことを目的にしている。したがって各項目は、
形成しなければならない判断ではなく、調べれば分かる事実にしてある。

## 基準

以下の全てを同時に満たすこと:

| # | 基準 | 確認方法 |
|---|---|---|
| 1 | **月次訓練を 6 回連続で合格**（スキップ無し） | 訓練記録。スキップしたステップは合格ではない |
| 2 | **4b の失敗が一度も無い** | 封じ込めだけは譲れない。sandbox が保たなかった実績が 1 回でもあればカウントはリセット |
| 3 | **gem-agent だけで完了した実タスクが、異なる月に 2 件**（本番に出す品質） | 訓練の締めの 2 つの問い（ステップ 8）が両方 yes |
| 4 | **訓練ステップを塞ぐ open issue が無い** | issue tracker |
| 5 | **直近 3 か月に config / CLI の破壊的変更が無い** | CHANGELOG。フラグが動いたフォールバックは記憶で使えない |
| 6 | **モデル廃止サイクルを 1 回乗り越えている** | Gemini の世代が廃止されても、コード変更なしに設定だけで動き続けた実績 |
| 7 | **クリーンマシンからの導入が通る** | 未導入マシンで `brew install nlink-jp/tap/gem-agent` → 訓練ステップ 1–2 |

6 か月は恣意的な数字ではない。**誰も触らなくてもこのツールを壊す 3 つ** —
macOS のポイントリリース、Gemini のモデル廃止予告、認証情報の期限切れ —
を少なくとも 1 回ずつ跨ぐ長さである。

## 昇格で変わること

- **series と umbrella**: リポジトリを `cli-series` へ移し、submodule ポインタも
  移す。カタログと org profile の行も追随する。
- **契約**: インターフェースの安定性が約束になる。破壊的変更は CHANGELOG の 1 行
  ではなく、組織の破壊的変更プロセス（利用者確認 → 互換案 → 実装）を通る。
- **変わらないこと**: 訓練。昇格は「もう鍛えなくてよい」ことではない — 基準を
  満たせたのは訓練があったからで、昇格後にやめれば、安定性の約束を背負ったまま
  腐ることになる。

## 昇格ではないもの

機能追加のご褒美ではない。gem-agent のスコープは意図的に Claude Code の中核 2 割
（RFP §3）であり、昇格を狙って機能を足すのは存在理由に反する。上記の基準に機能の
数は一切入っていない。

急ぐものでもない。lab-series に留まる運用上のコストはゼロ — どちらでも導入・
リリース・訓練は行われる。昇格が買うのは「他人に対する安定性の約束」だけであり、
gem-agent の利用者は現在 1 名である。
